# Week 3 Monday: pilot cohort selection

## Objective

Define a representative 10–20 sample pilot for resource calibration
and detection of systematic workflow failures before production.


## Pilot selection principles

The pilot should represent biological and technical variation rather
than consist only of easy or randomly selected samples.

Selection criteria include:

- organism;
- genome size 1C;
- ploidy;
- amount of input sequencing data;
- expected coverage feasibility;
- organelle-filtering behaviour;
- read-length behaviour;
- local versus remote input where useful;
- previously observed problematic cases.
