# Baseline Pipeline Input/Output Inventory

| Stage                                      | Primary input                                                                                      | Primary output                                                                          | Published location                                                                                       | Output role                      |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- | -------------------------------- |
| Samplesheet validation                     | Original samplesheet CSV                                                                           | Validated samplesheet: `samplesheet.validated.csv`                                                                 | `${params.outdir}/pipeline_info/`                                                                        | Intermediate                     |
| Paired-end read audit                      | Paired-end FASTQ files, R1 and R2                                                                  | Pair-audit report: `${meta.id}.pair_audit.tsv`                                                                     | `${params.outdir}/raw_qc/pair_audit/`                                                                    | Quality control                  |
| Raw FASTQ statistics                       | Paired-end FASTQ files, R1 and R2                                                                  | Raw-read statistics report: `${meta.id}.raw_fastq_stats.tsv`                                                       | `${params.outdir}/raw_qc/fastq_stats/`                                                                   | Quality control                  |
| Target read-length selection               | Paired-end FASTQ files, R1 and R2                                                                  | Target-length table: `${sample_id}.target_length.tsv`                                                              | `${params.outdir}/length_normalization/target_length/`                                                   | Intermediate                     |
| Fixed-length normalization                 | Paired-end FASTQ files and target-length table                                                     | Length-normalized reads: `${meta.id}_R*.fixed.fastq.gz`; cropping report: `${meta.id}.crop_report.tsv`             | `${params.outdir}/length_normalization/cropped_reads/`; `${params.outdir}/length_normalization/reports/` | Intermediate and quality control |
| Organelle filtering                        | Length-normalized paired-end reads and organelle reference FASTA                                   | Organelle-depleted reads: `*_R*.organelle_filtered.fastq.gz`; filtering report: `*.organelle_filter_report.tsv`    | `${params.outdir}/organelle_filter/fastq/`; `${params.outdir}/organelle_filter/reports/`                 | Intermediate and quality control |
| Coverage planning                          | Organelle-depleted paired-end reads, target-length table, genome size, ploidy, and target coverage | Coverage plan: `${sample_id}.coverage_plan.tsv`                                                                    | `${params.outdir}/coverage_sampling/plans/`                                                              | Intermediate                     |
| Paired-read subsampling                    | Organelle-depleted paired-end reads and coverage plan                                              | Subsampled reads: `${meta.id}_R*.sampled.fastq.gz`; sampling report: `${meta.id}.sampling_report.tsv`              | `${params.outdir}/coverage_sampling/sampled_reads/`; `${params.outdir}/coverage_sampling/reports/`       | Intermediate and quality control |
| RepeatExplorer formatting and interleaving | Subsampled paired-end reads, R1 and R2                                                             | RepeatExplorer-compatible FASTA: `${meta.id}.repex.fasta`; formatting report: `${meta.id}.repex_format_report.tsv` | `${params.outdir}/repex/fasta/`; `${params.outdir}/repex/reports/`                                       | Final                            |
| RepeatExplorer FASTA validation            | RepeatExplorer-compatible FASTA                                                                    | Validation report: `${meta.id}.repex_validation.tsv`                                                               | `${params.outdir}/repex/validation/`                                                                     | Final quality control            |
